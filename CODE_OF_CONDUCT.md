# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. Summary of expectations:

- Be respectful and constructive in issues, reviews, and discussions.
- No harassment, discrimination, or personal attacks.
- Focus criticism on code and ideas, with reproducible evidence.

Violations can be reported via a private GitHub Security Advisory or by
emailing the repository owner. Maintainers will review reports promptly and
may remove offending content or restrict participation.
